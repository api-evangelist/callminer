# CallMiner

> CallMiner is a conversation intelligence and contact-center analytics company. Its Eureka platform captures and analyzes omnichannel customer interactions — recorded and real-time audio, screen recordings, chat, email, surveys and video — to produce customer experience, quality management, risk and compliance, fraud detection and sales effectiveness insight. CallMiner exposes an OAuth 2.0 protected developer API on regional `api*.callminer.net` hosts, secured by its own IdentityServer-based identity provider at `idp*.callminer.net`.

## Access model

- The developer API is **not publicly documented**. Swagger UI is served from the API host but redirects to an interactive CallMiner login.
- Client credentials (`client_id` / `client_secret`) are issued by CallMiner, not through self-service signup.
- `developer.callminer.com` and `partner.callminer.com`, cited by third-party directories, do **not resolve** (NXDOMAIN, verified 2026-08-09).
- `https://api.callminer.net/robots.txt` is `User-agent: * / Disallow: /`.

## APIs

- [CallMiner Eureka Ingestion API](https://api.callminer.net/swagger): Asynchronously add or update media and metadata for audio and text-based contacts in a Eureka tenant. Base URL `https://api.callminer.net`. OAuth scope `https://callminer.net/auth/platform-ingestion`. Reference is login-gated.
- [CallMiner Eureka Bulk Export API](https://api.callminer.net/bulkexport/swagger): Create and poll bulk export jobs that extract contact, transcript, score and metadata datasets. Base URL `https://api.callminer.net/bulkexport/api`. OAuth scope `https://callminer.net/auth/platform-bulkexport`. Reference is login-gated.

## Authentication

- [OpenID Connect discovery](https://idp.callminer.net/.well-known/openid-configuration): Issuer `https://idp.callminer.net`. Grants: `authorization_code`, `client_credentials`, `refresh_token`, `implicit`, `password`, `device_code`. PKCE `S256` supported. Token endpoint auth: `client_secret_basic`, `client_secret_post`.
- [Token endpoint](https://idp.callminer.net/connect/token): `grant_type=client_credentials` for server-to-server integrations.
- [JWKS](https://idp.callminer.net/.well-known/openid-configuration/jwks): RS256 id_token signing keys.

## Regions

CallMiner runs region-isolated API and identity hosts: US (`api.callminer.net` / `idp.callminer.net`), US-FISMA (`apif`/`idpf`), UK (`apiuk`/`idpuk`), AU (`apiaus`/`idpaus`), CA (`apica`/`idpca`), EU (`apiew`/`idpew`).
